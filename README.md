# Rasu Games — Node.js / Express Website

## Run locally
```bash
npm install
npm start
```
Then open http://localhost:3000

## Hero video
The homepage hero uses the supplied YouTube gameplay video (muted autoplay, loop, playsinline). You must run the site through Node/Express; do not open index.html directly with file://.

If autoplay is blocked by the browser, click/reload once; the video remains an embedded YouTube background.
