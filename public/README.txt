RASU GAMES — FOOTBALLER NAME GENERATOR

Files:
- index.html
- styles.css
- app.js
- names.json
- server.js (optional Transfermarkt proxy)

Transfermarkt squad tool:
1. Enter TEAM NAME (example: Fenerbahçe Istanbul)
2. Enter TRANSFERMARKT CLUB ID (example: 36)
3. The site generates ONLY this URL shape:
   https://www.transfermarkt.com.tr/{team-slug}/kader/verein/{id}
4. Click LOAD SQUAD.

Recommended for reliable Transfermarkt access:
- Install Node.js 18+.
- Run: node server.js
- Open: http://localhost:8080

The browser first tries the local /api/transfermarkt proxy, then readable public fallbacks. No /startseite/ URL is generated by the app.
